# Contributing to TSP Thermal

We'd love your help! TSP Thermal is a collaborative project exploring NP-complete problem reductions, and there are many ways to get involved.

## Ideas for Collaborators

- 📊 **Visualizations**: Draw graphs, animate reduction steps, show transformation chains
- ⚡ **Algorithm Optimization**: Improve performance for larger problem sizes
- 🧩 **New Problem Types**: Add more NP-complete problems and reductions
- ✅ **Testing**: Build unit tests for reduction correctness and edge cases
- 📚 **Examples**: Create curated problem libraries and test cases
- 🎨 **UI/UX**: Improve interface, accessibility, and user experience
- 📖 **Documentation**: Enhance explanation of concepts and algorithms

## Getting Started

1. **Fork the repo** to your GitHub account
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/tsp-thermal.git
   cd tsp-thermal
   ```
3. **Create a feature branch** for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test thoroughly
5. **Commit with clear messages**:
   ```bash
   git commit -m "Add: clear description of what you changed"
   ```
6. **Push to your fork** and **submit a Pull Request**
   - Include a clear description of what you changed and why
   - Reference any related issues

## Questions?

- **Open an issue** to discuss ideas or report bugs
- **Start a discussion** for questions or brainstorming
- **Tag maintainers** if you need clarification

## Code Style

- Keep it simple and readable
- Comment complex logic, especially around reduction algorithms
- Test your changes in multiple browsers (Chrome, Firefox, Safari)

Thank you for contributing! 🚀
