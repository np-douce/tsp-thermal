NP-douce

Hamiltonian cycle, TSP theory calculations, and 3-SAT reduction tools.

Offline browser app

3-SAT to Hamiltonian Cycle

Uses the compressed polynomial reduction with the degree-2 forced-edge precheck. The optional third number on the first line adds forced padding nodes.

Vertex Cover to Hamiltonian Cycle

First line is vertices k optional_padding, then one undirected edge per line. Example: 4 2 followed by 1 2, 2 3, 3 4.

Clique to Hamiltonian Cycle

First line is vertices k optional_padding, then one undirected edge per line. Example: 5 3 followed by 1 2, 1 3, 2 3.

Independent Set to Hamiltonian Cycle

First line is vertices k optional_padding, then one undirected edge per line. Example: 5 3 followed by 1 2, 2 3, 3 4, 4 5.

Set Cover to Hamiltonian Cycle

First line is universe_size set_count k optional_padding, then one set per line using element numbers. Example: 5 4 2 followed by 1 2, 2 3 4, 4 5, 1 5.

X3C to Hamiltonian Cycle

First line is universe_size set_count optional_padding, then one 3-element set per line. Example: 6 4 followed by 1 2 3, 4 5 6, 1 4 5, 2 3 6.

Graph Coloring to Hamiltonian Cycle

First line is vertices edges colors optional_padding, then one undirected edge per line. Example: 4 6 4 followed by all six edges of K4.

Hamiltonian Pairs

One undirected edge per line, like u v. Listed edges get weight -1; all others are 0.

Weight Matrix

First line is n, followed by an n x n symmetric weight matrix.

Euclidean Points

First line is n, followed by x y point coordinates.

Manual Complete Graph

First line is n, then one upper-triangle weight per line in order: (1,2), (1,3), ....
